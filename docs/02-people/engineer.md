# Engineer — Persona & Work Map

Status: RESEARCHING / DESIGN HYPOTHESIS

## Core responsibility
Translate project design and requirements into technically correct site execution, verification, troubleshooting, testing, and evidence.

## HILTECH should remove
- Repeated requests for drawings/specs already attached to the project/site.
- Manual reconstruction of test history.
- Searching WhatsApp for the latest drawing.
- Unstructured photo evidence.
- Re-entering serials, measurements, and site notes later in the office.

## Primary experience
### Engineering Work
- Assigned projects and sites.
- Latest approved drawings/specifications.
- Technical work orders.
- Tests due.
- Issues requiring diagnosis.
- Assets and links requiring verification.
- Technical approvals/queries.
- Previous history for the same site/asset/link.

## Typical flow
Site/task -> context -> latest drawing/spec -> perform/inspect -> capture measurement/test/evidence -> associate evidence with correct object -> flag issue or complete technical review.

## Structured evidence examples
- OTDR result linked to fiber/link.
- Fluke result linked to copper link.
- Rack photo linked to rack.
- Device serial linked to installed asset.
- Measurement linked to task/site.
- Technical note linked to issue.

## Important product rule
Evidence must not live as orphan files. Every technical artifact should be attached to the object it proves.
