# Sales / Tenders — Persona & Work Map

Status: RESEARCHING / DESIGN HYPOTHESIS

## Core responsibility
Turn market opportunities into qualified, priced, technically valid, contractable work that can transition cleanly into delivery.

## Primary home
- New leads.
- Active opportunities.
- Tender deadlines.
- Site visits required.
- Technical clarifications.
- Quotes awaiting internal review.
- Quotes awaiting client response.
- Won/lost work.
- Contracts awaiting handoff.
- Existing clients with expansion/maintenance opportunities.

## Opportunity lifecycle
LEAD -> QUALIFIED -> DISCOVERY/SITE_VISIT -> SOLUTION/SCOPE -> COSTING -> INTERNAL_REVIEW -> QUOTE/TENDER_SUBMITTED -> NEGOTIATION -> WON / LOST / ON_HOLD -> CONTRACTED -> DELIVERY_HANDOFF

Exact states require validation.

## Key rule
No sales/tender record should become a dead CRM card after winning. Winning should create/seed the project reality without re-entering scope, client, sites, commercial terms, BOQ, documents, contacts, and commitments.

- inbound website/RFQ
