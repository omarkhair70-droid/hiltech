# Complete Role Experience — Supervisor

Status: PRODUCT MODEL v0.1 / NOT BUILD-READY

## Product thesis
Supervisor owns today's site truth: people, work, tools, materials, blockers, quality, and closeout.

## Mobile-first home
### My Site Today
- crew
- planned work
- started/completed
- blocked
- materials
- equipment
- evidence awaiting review
- critical issues
- tomorrow requirements

## Key commands
- confirm/start site day
- assign/reassign task
- confirm crew
- receive site material
- confirm tool/equipment custody context
- review technician evidence
- request rework
- report blocker
- request resource
- close daily site report

## Desktop/tablet
- work distribution
- daily plan
- crew/resource board
- evidence review
- issue list
- tomorrow preparation

## Automation
- show missing crew/resource before shift
- aggregate technician completions
- generate draft daily report from accepted activity
- identify missing evidence before close
- derive tomorrow resource needs from plan

## Notifications
- assignment/resource changed
- technician blocker
- delivery arriving
- urgent drawing/spec change
- PM feedback
- equipment return requirement

## Offline
Site-day essentials must remain usable offline.

## Edge states
- technician absent
- tool reserved but unavailable
- partial material delivery
- duplicate checkout
- work completed without evidence
- task reassigned while technician offline
- site access denied

## Cross-role
PM -> supervisor plan.
Warehouse -> resource issue.
Technicians -> execution/evidence.
Supervisor -> PM accepted site truth.
Engineer -> technical instructions/acceptance.

## Success
End-of-day status is a by-product of work, not a separate reconstruction exercise.
