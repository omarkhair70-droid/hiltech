# Complete Role Experience — Client

Status: PRODUCT MODEL v0.1 / NOT BUILD-READY

## Product thesis
The client should experience HILTECH as an organized operating partner, not a contractor that disappears into chats after award.

## Client home
# My HILTECH
- Active projects
- Sites
- Actions waiting for me
- Recent progress
- Documents
- Support/maintenance
- Invoices where role allows
- New request

## Client organization roles
- executive
- project manager
- technical
- finance
- viewer

Each sees different allowed project/commercial data.

## Key commands
- view project/site
- review client-visible progress
- approve/reject variation or milestone
- acknowledge handover/document
- report support issue
- request new work
- view invoice/status where authorized

## Automation
- milestone update after internal approval
- pending client-action reminder
- ticket/SLA updates
- maintenance reminders
- delivered site becomes reusable context for expansion

## Privacy
Never expose:
- internal margin/cost
- employee payroll
- supplier comparisons
- unrelated client/project
- internal notes/evidence not approved for client

## Edge states
- client user belongs to multiple organizations
- client approver changes
- approval requested on outdated version
- support issue not under maintenance contract
- project progress blocked by client action
- external user account inactive

## Success
Client can understand and act without asking HILTECH for basic status/documents repeatedly.
