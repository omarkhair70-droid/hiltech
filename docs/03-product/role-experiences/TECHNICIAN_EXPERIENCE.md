# Complete Role Experience — Technician

Status: PRODUCT MODEL v0.1 / NOT BUILD-READY

## Product thesis
The technician should not navigate an ERP. HILTECH should show the next work, exact context, required resources, and required proof.

## Mobile home
# Today
Each job:
- time
- site
- task
- supervisor
- required tools/materials
- important instruction
- status

## Job flow
Open -> Context -> Start -> Work -> Scan/Measure/Capture -> Problem if blocked -> Complete -> Sync/Review.

## Key commands
- start job
- view drawing/instruction
- scan QR/barcode
- record material used
- attach photo/test/measurement
- report blocker/damage
- complete job
- request/confirm tool return
- view own employee self-service

## Employee self-service
- own payslip
- leave
- expense status
- assigned tools/assets
- training/certification
- relevant announcements

## Motion/interaction implication
Technician experience should be highly tactile and state-driven:
- clear progress
- strong scan feedback
- visible offline/sync state
- large actionable controls
- minimal typing where structured input/scan is possible

Final visual system waits for design research.

## Offline
Core requirement.
Job bundle downloaded before site:
- task
- site
- drawings
- instructions
- required evidence schema
- relevant assets/materials

Writes queue locally and sync visibly.

## Automation
- warn before completion if evidence missing
- preselect current project/site after explicit job start
- suggest scanned asset context when unambiguous
- queue uploads
- retry sync
- remind overdue checked-out equipment

## Notifications
- job assigned/changed/cancelled
- tomorrow schedule
- drawing update
- supervisor rework
- site access instruction
- own expense/leave/payroll status

## Edge states
- no network
- camera prohibited at site
- wrong QR
- duplicate scan
- job changed while offline
- material quantity discrepancy
- sync failure
- phone lost/replaced
- permission revoked mid-job

## Success
A technician can complete a valid site visit without asking “what am I supposed to do?” or re-entering evidence later.
