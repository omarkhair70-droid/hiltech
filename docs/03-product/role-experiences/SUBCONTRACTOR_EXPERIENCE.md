# Complete Role Experience — Subcontractor

Status: PRODUCT MODEL v0.1 / NOT BUILD-READY

## Product thesis
External execution should generate the same structured project truth as internal execution where practical.

## Home
- Assigned work packages
- Sites/schedule
- Required documents
- Open issues
- Evidence/rework
- Acceptance/commercial milestone where allowed

## Key commands
- accept/clarify work
- view assigned scope
- submit execution evidence
- report issue/RFI
- confirm resources
- submit completion
- respond to rework
- view acceptance status

## Permissions
Subcontractor sees only assigned:
- project/work package
- sites
- required drawings/specs
- evidence requirements
- approved commercial milestone context

No access to unrelated project internals, HILTECH payroll, or broad client financial information.

## Integration with HILTECH field truth
Subcontractor completion:
-> HILTECH review
-> accepted/rework
-> project progress
-> milestone/payment eligibility where contract allows.

## Edge states
- subcontractor uses HILTECH-owned tools/material
- multiple subcontractors on same site
- work completed but evidence missing
- client rejects externally executed work
- subcontractor user removed mid-project

## Success
HILTECH retains delivery visibility and audit even when work is external.
