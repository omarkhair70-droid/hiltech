# HILTECH Desktop Surface Map

Status: EXPERIENCE MODEL v0.1 / NOT VISUAL DESIGN / NOT BUILD-READY

## Purpose
Define desktop HILTECH as the high-density, high-control expression of the same product truth.

Desktop is optimized for:
- planning,
- comparison,
- bulk work,
- deep review,
- tables,
- documents,
- financial control,
- project command,
- administration,
- monitoring.

It is not a separate platform/business system.

---

# 1. Shared Desktop Shell

Potential shared capabilities:
- role/context-aware navigation
- global search

- Inbox/action queue

- keyboard shortcuts
- notification/status center
