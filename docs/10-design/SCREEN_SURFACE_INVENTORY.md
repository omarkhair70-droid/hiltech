# HILTECH Screen / Surface Inventory

Status: EXPERIENCE INVENTORY v0.1 / NOT VISUAL DESIGN

## Purpose
Enumerate the actual surfaces HILTECH needs so no screen, state, or role is invented ad hoc during implementation.

A "surface" may render differently on mobile/desktop but refers to one product responsibility.

# 21. Required State Set Per Surface

Every relevant screen must explicitly design:

- Loading.
- Loaded.
- Empty.
- Partial.
- Stale.
- Offline cached.
- Offline action available.
- Offline action unavailable.
- Syncing.
- Sync failed.
- Conflict.
- Permission denied.
- Re-auth required.
- Object changed/superseded.
- External integration unavailable.
- Error with safe retry.
- Terminal/closed state.

Not every state applies to every surface, but it must be evaluated.
