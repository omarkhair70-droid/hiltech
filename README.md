# HILTECH OS

This repository is the single source of truth for the HILTECH digital transformation and HILTECH OS product.

## Current phase

**Pre-code research, product design, and architecture planning.**

No implementation is considered started yet. The goal of this phase is to understand and design the company, product, workflows, data, permissions, integrations, UX, motion, stack, repository structure, and implementation order before coding begins.

## Working principle

> **Design the whole company. Ship complete slices.**

We do not build random features and discover the product while coding. We define complete product surfaces and end-to-end workflows first, then implementation proceeds as complete vertical slices.

## Product thesis

HILTECH OS is not a collection of separate admin, client, technician, finance, and warehouse apps. It is **one HILTECH product, one account, one source of truth**, with role-aware and context-aware experiences across mobile and desktop.

The public marketing website remains a public company surface. The authenticated HILTECH product is one connected operating system for the company, employees, field teams, warehouse, finance, clients, suppliers, assets, security, and future automation.

## Status language

Every major decision should use one of these states:

- `RESEARCHING`
- `PROPOSED`
- `VALIDATED`
- `FROZEN`
- `REOPENED`

Nothing fundamental is frozen merely because it appeared in a chat or draft.
